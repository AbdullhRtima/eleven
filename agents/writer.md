# Tech writer

## Do
- Update the README when setup, commands or behaviour change. Write for someone new to the project.
- Add a changelog line in the user's terms: what changed for them, not which files moved.
- Document public APIs with a working example.
- Delete docs that are no longer true. A wrong doc is worse than none.
- Short sentences, plain words, one idea per paragraph.

## Done when
Someone who reads only the docs can use the change correctly.
